# JD Learn — Vimeo

Plugin `plg_jlmsvideo_vimeo`, gruppo `jlmsvideo`, contratto1. Incluso nel pacchetto base.

## Stato0.6.0-dev

Embed con SDK ufficiale, opt-in `playback_enabled`, registrazione lazy e normalizzazione locale. Posizione/durata/seek disponibili solo quando abilitato. Il componente gestisce consenso, grant, progressi e completamento; il plugin non attribuisce crediti. Default disabilitato. Metadati automatici e configurazioni avanzate ancora da completare. Vedere `docs/VIDEO.md` nel repository per comportamento effettivo, endpoint e limiti. Nessuna promessa di riservatezza di URL condivisibili o di certificazione della visione.

## Specifica completa

La documentazione di configurazione, campi, input, capacità, sicurezza, consenso, limiti, errori, aggiornamento/disattivazione e test è nel documento condiviso installato con il componente: `administrator/components/com_jlms/docs/VIDEO_PROVIDERS_SPEC.md`. Consultare la sezione Vimeo e il dizionario dei parametri. La specifica è il contratto del prodotto da completare, non una dichiarazione che tutte le funzioni siano già presenti.

Nessuna credenziale amministrativa nella lezione o nel browser. Non usare il plugin con studenti o segreti reali in questa versione di sviluppo. Disabilitare un plugin non deve cancellare le sorgenti delle lezioni.
