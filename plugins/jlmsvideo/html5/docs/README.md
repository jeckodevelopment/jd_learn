# JD Learn — HTML5

Plugin `plg_jlmsvideo_html5`, gruppo `jlmsvideo`, contratto1, incluso nel pacchetto base. Incremento0.8: MP4/H.264 con AAC facoltativo, upload diretto alla lezione, durata server, player nativo e consegna Joomla protetta con PHP limitato o Nginx interno. Richiede abilitazione esplicita, ffprobe e configurazione privata nel componente.

Guida operativa inclusa: `administrator/components/com_jlms/docs/HTML5_VIDEO.md`. La specifica completa di tutti i provider rimane in `VIDEO_PROVIDERS_SPEC.md`. Altri codec/storage, sottotitoli, cleanup, collaudo decoder/browser e benchmark sono ancora da completare. Nessun file pubblico, segreto o video utente è incluso nel pacchetto.
