# Documentazione JD Learn0.2.0-dev

Questo incremento implementa le fondamenta, i corsi e il programma in bozza con moduli/lezioni. La specifica dei provider descrive il comportamento richiesto al prodotto completo: i player, i token e lo storage protetto non sono ancora attivi. Vedere README e IMPLEMENTATION_STATUS nella repository.

La specifica completa di sicurezza e dei quattro plugin video è inclusa in VIDEO_PROVIDERS_SPEC.md. Nessuna credenziale reale è inclusa. Gli identificativi CSS e gli override effettivamente disponibili sono documentati in docs/FRONTEND_CSS.md nella repository.
